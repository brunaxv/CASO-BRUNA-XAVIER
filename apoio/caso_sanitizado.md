# Caso sanitizado para consulta — CA-2026-014

> **Aviso:** este caso é fictício e foi sanitizado para fins de consulta. Não contém dados que identifiquem pessoas reais.

## Resumo do caso

Uma candidata participou de um processo seletivo fictício para uma vaga de estágio. Antes da entrevista remota, ela solicitou um recurso de acessibilidade. A entrevista foi remarcada e, posteriormente, a candidatura foi encerrada sem apresentação dos critérios detalhados de avaliação.

A candidata relatou uma possível fala inadequada sobre o impacto de adaptações no ritmo de trabalho e questionou se o pedido de acessibilidade influenciou o resultado do processo.

## Transformações aplicadas

| Informação presente no relato bruto | Tratamento na versão sanitizada |
| --- | --- |
| Nome da candidata | Substituído por “candidata” |
| E-mail, telefone e endereço | Removidos |
| Data de nascimento e CPF | Removidos |
| Empresa e vaga específicas | Generalizadas como processo seletivo fictício de estágio |
| Informação de saúde | Substituída por “solicitou um recurso de acessibilidade” |
| Datas exatas | Omitidas, mantendo apenas a sequência dos fatos |

## Informações úteis para análise

- Houve pedido prévio de acessibilidade para uma entrevista remota.
- A entrevista foi reagendada.
- A comunicação de encerramento não trouxe justificativa detalhada.
- A documentação disponível é suficiente para indicar necessidade de revisão humana, mas não para concluir a causa da eliminação.

## Limites de uso

Esta versão pode ser utilizada em consultas, treinamento e análise de fluxo, desde que permaneça vinculada ao seu caráter fictício. Ela não deve ser usada para identificar indivíduos, inferir condições de saúde ou representar fatos de uma organização real.
