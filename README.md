# Estudo de caso fictício: acessibilidade em processo seletivo

> Todos os conteúdos deste repositório são inventados para fins educacionais. Não há pessoas, empresas, fontes ou ocorrências reais representadas aqui.

## Finalidade

Este repositório demonstra como documentar um relato fictício com dados pessoais simulados, identificar informação sensível, gerar uma versão sanitizada para consulta e registrar etapas de verificação, auditoria e revisão humana. Também apresenta limites para o compartilhamento de informações e para o uso de IA nesse fluxo.

## Para quem é este material

O conteúdo foi preparado para estudantes, avaliadores e colaboradores autorizados que desejem compreender a organização de um estudo de caso. Não deve ser utilizado como orientação jurídica, política institucional real ou base para decisões sobre pessoas reais.

## Orientação para outra pessoa que for usar o repositório

1. Leia primeiro este README, depois `docs/especificacao.md` e `docs/limites_e_sigilo.md`.
2. Para compreender o caso sem consultar identificadores simulados, comece por `apoio/caso_sanitizado.md`.
3. Use `entrada/relato_bruto.md` somente se a atividade exigir observar a classificação dos dados simulados.
4. Mantenha em todos os usos o aviso de que o caso e as fontes são fictícios.
5. Não inclua dados pessoais, dados de saúde, documentos confidenciais ou fatos reais no material.
6. Trate qualquer conteúdo produzido por IA como apoio de redação e análise; revise-o humanamente antes de reutilizá-lo.

## Limites importantes

O estudo não conclui que houve discriminação, não atribui responsabilidade e não substitui investigação, aconselhamento especializado ou revisão humana. Para regras completas de confidencialidade e IA, consulte [docs/limites_e_sigilo.md](docs/limites_e_sigilo.md).
